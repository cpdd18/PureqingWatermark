# 纯情の水印机

原生 iOS 照片水印工具。支持批量添加水印、模糊和相框，并将结果导出为 PNG。

需要 iOS 17 或更新版本。用 Xcode 打开 `PureqingWatermark.xcodeproj` 即可在模拟器运行。真机运行时，请在 Signing & Capabilities 中选择自己的 Team，并设置唯一的 Bundle Identifier。

动漫人脸检测使用 [nagadomi/lbpcascade_animeface](https://github.com/nagadomi/lbpcascade_animeface)。模型的 MIT 许可随 `AnimeFaceCascade.json` 保留。
